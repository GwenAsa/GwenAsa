# `01` / ABOUT

I'm **Asa** — an independent developer with a strong interest in GNU/Linux, open-source software, and thoughtfully designed applications.

I build Discord bots, developer tools, desktop applications, and web experiences. I also enjoy exploring Linux distributions, learning how systems fit together, customizing my environment, and making software work well on modest hardware.

This profile is my public development log: a place for projects, experiments, tools, and things I'm learning. I value practical engineering, readable code, deliberate design, and curiosity over collecting technology names.

> **Build things that are useful. Understand the systems beneath them. Keep exploring.**

# `04` / SELECTED BUILDS

A few projects that represent the kinds of things I enjoy making. Project status is stated explicitly; experiments and works in progress are not presented as finished products.

## [Cordium IDE](https://github.com/GwenAsa/cordium-ide)

**A purpose-built IDE for Discord application developers.**

A developer-focused environment for building and testing Discord bots, with workflows for command development, interaction previews, and debugging.

`Developer tools` `Discord` `Python` `discord.js` `Desktop`

## [Discy](https://github.com/GwenAsa/discy-free-premium-discord-bot)

**A modular multipurpose Discord bot.**

A Python-based community bot with separate cogs for moderation, utility, tickets, roles, giveaways, leveling, and other server features.

`Python` `discord.py` `SQLite` `Discord`

## More experiments

- **Gitcord** — a TypeScript and Discord.js project exploring bot development workflows.
- **Bendy's Inkkeeper** — a growing Discord community companion inspired by the Bendy universe.
- **Calendar Heatmap** — a local-first activity tracker concept using Tauri, Rust, and SQLite.
